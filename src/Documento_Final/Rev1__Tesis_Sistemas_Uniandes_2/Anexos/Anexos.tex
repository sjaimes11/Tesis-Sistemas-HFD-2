\section{Anexo A: Arquitectura del Sistema HFL}
\label{anx:arquitectura}

La arquitectura desplegada consta de tres capas principales y una extensión FOG opcional. La Figura~\ref{fig:anx_arquitectura_hfl_v7} resume el despliegue físico, los protocolos por enlace y la cobertura de ASCON-128 sobre cada canal.

\begin{figure}[H]
    \centering
    \includegraphics[width=\textwidth]{images/Anexos/hfl_v7_architecture.png}
    \caption{Arquitectura física del sistema HFL v7. La capa Cloud (PC) coordina las rondas con FastAPI y FedAvg ponderado. La capa Fog (Raspberry Pi) actúa como broker MQTT, etiquetador heurístico y entrenador local; en el modo FOG, una segunda Raspberry Pi participa como \emph{peer} y se comunica con el \emph{leader} mediante los topics \texttt{fog/weights} y \texttt{fog/global\_model} (línea discontinua). La capa Edge (ESP32-S3) ejecuta inferencia TinyML sobre 13 features de flujo y publica datos al gateway. ASCON-128 cubre todos los canales en variantes \texttt{*\_ASCON\_*}; en variantes \texttt{*\_PLAIN\_*} los topics y endpoints usan sufijo \texttt{\_plain} con JSON sin cifrar.}
    \label{fig:anx_arquitectura_hfl_v7}
\end{figure}

A nivel narrativo, las capas se resumen así:

\begin{itemize}
    \item \textbf{Capa Edge:} $2 \times$ ESP32-S3 por gateway (un nodo \emph{normal} y un nodo \emph{simulated}), ejecutando inferencia TinyML y publicando \texttt{fl/features} hacia el gateway por MQTT cifrado con ASCON-128.
    \item \textbf{Capa Fog:} Raspberry Pi~4 actuando como broker MQTT (Mosquitto), gateway de entrenamiento local (etiquetado heurístico, buffer $N_s = 30$, entrenamiento Keras) y puente HTTP hacia el servidor.
    \item \textbf{Capa Cloud:} $1 \times$ PC ejecutando \texttt{server\_hfl.py} o \texttt{server\_hfl\_fog.py} (FastAPI), responsable de la agregación FedAvg ponderada por número de muestras y del dashboard analítico en tiempo real.
    \item \textbf{Extensión FOG:} Raspberry Pi líder y peer comunicándose por \texttt{fog/weights} y \texttt{fog/global\_model} para agregar entre gateways antes de reportar al PC mediante \texttt{/aggregate-from-fog}.
\end{itemize}

\section{Anexo C: Repositorio del Proyecto}
\label{anx:repositorio}

El código fuente completo, datasets y scripts de entrenamiento están disponibles en el repositorio del proyecto. Las carpetas relevantes para esta revisión son \texttt{hfl\_v7-RN} (MLP/RN con ASCON), \texttt{hfl\_v7-no-ascon-RN} (baseline MLP/RN con JSON plano), \texttt{hfl\_v7-CNN} (modelo CNN-1D con ASCON, estándar y FOG), \texttt{NotebooksAndModels} (entrenamiento offline y exportación de pesos), \texttt{Analisis de Modelos} (post-procesamiento por variante: \texttt{RN}, \texttt{no-ascon}, \texttt{CNN}, \texttt{CNN\_FOG}, \texttt{NIST}) y \texttt{Papers} (literatura base).
